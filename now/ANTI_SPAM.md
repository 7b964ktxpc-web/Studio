# «Сейчас» — anti-spam v1

## Goal

Новый пользователь должен получать только редкие и действительно локальные запросы.

### Request creation

- Максимум 3 исходящих вопроса на пользователя за 10 минут.
- Максимум 10 исходящих вопросов за час.
- Повторный вопрос с почти тем же текстом и той же точкой в течение 10 минут отклоняется.
- Пустой вопрос, вопрос длиннее 160 символов и запрос без валидной геопозиции отклоняются.
- Один запрос живёт максимум 10 минут.

### Push delivery

- Только opt-in пользователям (`is_available=true`).
- Только свежим presence (<5 минут).
- Только при точности геолокации <=50 м.
- Только в пределах 250 м от точки запроса.
- Используются ступени 50/100/150/250 м.
- Один recipient получает максимум один push на request.
- Один recipient получает не более 6 nearby-request push за час и 20 за сутки.
- Если пользователь уже ответил на запрос, повторный push ему не отправляется.
- Если пользователь отклонил два запроса подряд, следующий nearby push для него откладывается на 30 минут.

### Manual answers

- Ответ не требует push-согласия: пользователь может открыть карту и ответить вручную.
- Один пользователь отвечает на конкретный запрос только один раз в MVP.
- Ответ после `expires_at` отклоняется.

### Safety

- Не показывать телефон, имя, точные координаты или постоянный идентификатор отвечающего.
- Не отправлять push с точным адресом или координатами пользователя.
- Отдельно логировать rate-limit решения для последующего анализа abuse.

## Future

После первых реальных тестов лимиты пересматриваются по фактической частоте push и жалобам. Настройки должны оставаться серверными, чтобы менять их без обновления клиента.
