# Сейчас — MVP

Живой слой локальной информации для Новосибирска.

## Идея

Человек задаёт простой вопрос про конкретное место: «есть ли очередь?», «работает ли?», «есть ли товар?», «что там сейчас?». Система определяет его координаты и в боевой версии отправляет короткий запрос пользователям поблизости. Ответ становится свежим локальным сигналом.

## Что уже сделано

- mobile-first интерфейс;
- свободный вопрос;
- получение геолокации браузером;
- демо-жизненный цикл запроса: создан → ожидание → ответ;
- ответы одним тапом;
- локальное сохранение последнего запроса на 10 минут;
- карточки «Сейчас рядом»;
- черновая backend-схема в `schema.sql`.

Последний frontend-коммит: `dc1fe8ebc0868eca248ccf7b7aa52ea428c4d67a`.

## Следующий этап

1. Создать отдельный Supabase-проект именно для «Сейчас» — не использовать старую базу STO-NSK.
2. Применить `schema.sql` после создания проекта.
3. Добавить Auth и анонимный/гостевой сценарий.
4. Подключить Postgres Realtime для `questions` и `answers`.
5. Сделать Edge Function, которая выбирает пользователей в радиусе и создаёт уведомления.
6. Добавить Web Push, затем Telegram Mini App.
7. Добавить защиту от спама: cooldown, rate limit, срок жизни запроса и подтверждение геолокации.

## Принцип MVP

Не строим большую социальную сеть и не делаем каталог всех организаций. Первый продукт — максимально простой ответ на один вопрос: **«Что там происходит прямо сейчас?»**
