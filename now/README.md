# Сейчас — MVP

Живой слой локальной информации для Новосибирска.

## Первый сценарий

1. Пользователь задаёт вопрос: «Есть очередь в МФЦ?»
2. Система определяет место.
3. Находит людей рядом.
4. Отправляет им короткий запрос.
5. Ответ одним тапом становится свежим статусом места.

## MVP v0.1

- mobile-first web prototype;
- вопрос в свободной форме;
- запрос геолокации;
- карточки актуальных мест;
- подготовка к realtime/push flow.

Следующий технический этап: Supabase для `places`, `questions`, `answers`, `presence`, Realtime и Edge Functions; затем Web Push/Telegram Mini App.
