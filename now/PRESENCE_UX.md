# «Сейчас» — UX режима «Я рядом»

## Основной принцип

Nearby-запросы не должны быть включены автоматически. Пользователь сам включает режим **«Я рядом»**, когда готов иногда помогать людям поблизости.

## States

### OFF
- CTA: `Включить «Я рядом»`
- пояснение: `Получать вопросы только когда вы действительно рядом с местом`
- никакого background matching

### STARTING
- запрос разрешения геолокации;
- показываем, зачем нужна геолокация;
- если разрешение отклонено, режим остаётся OFF.

### ON / FRESH
- бейдж: `🟢 Я рядом`
- текст: `Можно получать вопросы рядом`
- показываем только собственный статус присутствия;
- heartbeat каждые 60 секунд;
- stale after 5 минут.

### DEGRADED
Если геолокация доступна, но точность хуже 50 м:
- бейдж `🟡 Точность низкая`;
- nearby push временно не отправляется;
- предлагаем оставить режим включённым и дождаться более точной позиции.

### OFF_AFTER_NAVIGATION
Если пользователь выключает режим:
- немедленно остановить watcher/heartbeat;
- отправить `available=false` при наличии backend;
- удалить локальный active presence marker;
- новые nearby push больше не разрешать.

## UX rules

1. Не показывать пользователю точные координаты других людей.
2. Не говорить «кто-то в 37 метрах»; использовать безопасную формулировку `человек рядом`.
3. Пока режим OFF, пользователь не должен получать nearby-request push.
4. При каждом новом push показывать короткий вопрос и одну основную кнопку ответа.
5. Не превращать режим в социальную ленту.
6. На экране профиля явно показывать, включён ли режим.
7. Режим должен быть легко выключить одним тапом.
